Import an activity from Word

  1. Download the Word template and fill it in (headings, numbered questions and an ANSWER KEY at the end; instructions are on its first page). Files that do not follow the template are not imported.
  2. Choose the file and press Check file. Nothing is saved until you press Import.
  3. The new activity is a draft: open it in the editor to review it and give it to your classes.
Have a LAS file? Let an AI tool prepare the import file

Open a generative AI tool that accepts files (for example ChatGPT, Claude or Gemini). Attach the Word template and your LAS file, then paste this prompt. Download the .docx it makes and choose it below. AI can make mistakes, so read the result and press Check file before importing.
